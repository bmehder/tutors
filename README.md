# Christian Tutors

Standalone React + Vite proof of concept styled with Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:5173 in your browser. No ChatGPT hosting or login is needed.

## Build

```sh
npm run build
npm run preview
```

The production website is generated in `dist/` and can be hosted on any static web host.

Tutor profiles, prices, and availability are illustrative. Signup discounts and demo bookings are saved in browser local storage. No payments are collected or emails sent.
